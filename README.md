# KPI_Analysis_Project
Analyze sales data, calculate Key Performance Indicators (KPIs), visualize the results, and provide business insights.
# KPI Analysis Project

## Overview
This project analyzes sales data using Python and Pandas to calculate important business KPIs.

## KPIs
- Total Revenue
- Average Revenue
- Conversion Rate
- Retention Rate
- Total Orders

## Technologies Used
- Python
- Pandas
- Matplotlib

## Output
- Revenue Dashboard
- KPI Summary
- Business Insights

## Business Insights
- Revenue increased every month.
- Conversion rate improved.
- Retention rate declined.
- Growth may not be sustainable without improving customer retention.
